# Cloudinary Media Library Location

The **Media Library** is the place in Cloudinary where you can view, organize, and manage all your uploaded assets.

## How to open it
1. Sign in to your Cloudinary account.
2. In the left‑hand navigation panel you will see several sections such as **Dashboard**, **Media Library**, **Upload**, **Settings**, etc.
3. Click **Media Library**.

![Media Library screenshot](/C:/Users/ASUS/.gemini/antigravity/brain/266bcd6e-9b0c-4996-9229-75c2ed6ec4d7/.user_uploaded/media_1794836088079_4552d3d3.png)

The screen shows a grid of thumbnails for all assets. From here you can:
- Browse existing images and videos.
- Create folders, tag assets, and search.
- Create unsigned upload presets (under **Settings → Upload → Upload presets**).

When you create an unsigned preset, you will later copy its **name** into your `.env` file as `VITE_CLOUDINARY_UPLOAD_PRESET` (or `REACT_APP_CLOUDINARY_UPLOAD_PRESET`).

---
**Tip:** If you cannot see the left navigation, make sure you are on the main Cloudinary console URL, e.g. `https://cloudinary.com/console`.
